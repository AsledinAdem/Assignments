# PRD Review

## Change 6: Made the single-screen scope explicit

- **Original:** The PRD said “one dashboard page” but did not rule out a sidebar or navigation.
- **Changed to:** The design requirements and acceptance criteria say there is no sidebar, no navigation menu, and no extra routes. Multiplayer and live anime data were also added to the excluded features.
- **Why:** The requirement calls for one dashboard screen and lists multiplayer and live anime data as outside the first version.
